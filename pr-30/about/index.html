// About DebugLED

Why DebugLED?
Have you ever wondered what the most important component is on a PCB?

Most would say the MCU, some would say the transistor, others a fuse. To me it's that simple diode that lights up when nothing else works. The Debug LED.

If you've ever designed Hardware, you know what I'm talking about.

The one single thing that you can rely on when nothing else is working. The one fundamental component that allows you to implement the more complex systems on the board.
Before SPI, before UART, before the display, before any other feedback system.
Sometimes, the only feedback system you have on the board.
The first thing you code when writting the firmware.

In those initial moments, it's the sole indicator that there's power, the MCU is working and processing your code and that, if all else fails, you'll have that one beacon of feedback from the hardware to debug your design and code.

And that's why, to me, this single tiny diode is the most important component in any PCB!

PS: Ok, let's not forget the resistor, otherwise we just have a burned LED 😅
