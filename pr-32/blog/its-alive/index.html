It's Alive! ⚡

2026-07-21

It’s alive!!

It’s official! The debugled.com website is up and running!!

It’s been a few months cooking, but it’s finally time to (soft) launch this website!

It feels like it has been a long journey to get here. But damn, was it worth it!

The website is starting to take shape now that is is more populated. There are 4 published projects and this is the 5th blog post. Feels good to finally see some content here!

Next steps

Now that the website has a proper domain and isn’t living on my github page, it is time to polish it up, keep adding content and then send it out into the world!

I will be adding content more regularly now and making some more improvements to the website. My goal is to publish at least a blog post per week and keep the projects updated as I work on them.

I’m still not completely sold on the current UI, so I might focus on that after wrapping up the some currently active projects, like the Akko Crystal Silver U1 switch review and the Home Server build.

I’ve been solely focused on the website for 2 days now, so I’ll be focusing on the projects for the rest of the week so I can make some good progress on them. I’ll be back later for some more updates!

Until then, have fun! ✌
