Summer Projects

2026-07-20

What’s cookin’?

2 Blogposts AND 3 projects in the same day?! Is it christmas already?!

These past few weeks have been busy. The good kind of busy. I’ve started 3 new projects, for better or for worse. And maybe gotten myself into some more long term work along the way?

Where am I? Who am I?

Keyboard Switch Review

I got an invitation to review some tech about a month ago. To which I said yes, despite never having done it in this way. I’m wrapping up a video on it. It’s been fun so far 😄

You can read all about it in this blog post. There’s also a project page.

Home Server

Meanwhile, I started to seriously consider building a Server to self-host some stuff, since my Raspberry Pi 4 is already dealing with my whole home automation setup and a PiHole server for DNS. This was somewhat put on hold while I finish the Switch Review. I’m sourcing the components I’m missing from 2nd hand markets and waiting on some replies.

Desktop PSU Repair

As a side-quest to this whole self hosting Server build, I remembered I have an old burnt out PSU lying around. “Why not try to fix it? It’ll be good HW repair experience!” I thought. So with no idea where to start, I set out to figure it out.

Thankfully, Reddit was a lot of help. I now have some next steps to take and I’m just, again, waiting to finish the Switch Review video.

Website & others

I took today off to write up all these projects and blog posts to try and reduce the backlog for this website :’)

I’ve been doing some other random stuff, like installing a washing machine cabinet door, working out, baking bread or just enjoying the summer and going to the beach for a couple hours. These things don’t take much time on their own, but it adds up.

I’m also feeling like getting back into photography. I want to get a mirrorless camera, but the one I want is a bit expensive. Might hold off on this one for a bit and use my good ol’ DSLR!

What’s Next

As you probably already understood by now I’m finishing the Switch Review video before I continue anything else. This might lead to future projects in the video and/or tech review area. I am excited about that, not gonna lie.

After that I want to boot up the server, but that’s somewhat pending on getting the components I need from a 2nd hand market in which I can’t control the delivery times. I expect this to take some weeks to get sorted.

Meanwhile I’ll try to repair the PSU. I learned about PSU testers and that seems like a cool piece of tech.

That’s it for now. Check out the project pages for more info and check back in later for some more blog posts 😀

In summary: lots of ideas, lots of stuff to do, not enough time!

We’ll get there! I feel like everything’s in place to work out and I’m excited about what’s to come!
